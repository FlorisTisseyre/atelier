# Atelier

Bienvenue. Ce dépôt contient tout ce qu'il faut pour participer.

1. Commencez par `SETUP.md` : installation, lancement du back et du front,
   puis votre agent de code.
2. Une fois que tout tourne, ouvrez `backlog.md` : le brief de la première
   phase.

L'atelier se déroule en deux phases. La fiche de la phase 2 vous sera remise le
moment venu.

Le code support (back Spring Boot + front React) n'est pas versionné ici : vous
le clonez dans `app/` en suivant `SETUP.md`.
